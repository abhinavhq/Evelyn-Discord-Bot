⚙️ Setup Guide
1️⃣ Clone the repository
git clone https://github.com/your-username/Discord-Bot.git
cd Discord-Bot
2️⃣ Install dependencies
pip install -r requirements.txt
3️⃣ Create .env file
DISCORD_TOKEN=your_token_here
4️⃣ Run the bot
python bot.py

🔐 Security
Never share your .env file
